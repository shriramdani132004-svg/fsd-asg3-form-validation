# Assignment 3 - JavaScript Form Validation

A user registration form built using HTML, CSS, and JavaScript.

## Fields

- Full Name
- Email
- Phone Number
- Password
- Confirm Password

## Validation

JavaScript validates:

- Required fields
- Name format
- Email format
- 10-digit phone number
- Password length
- Uppercase character
- Lowercase character
- Number in password
- Password confirmation

## Technologies

- HTML5
- CSS3
- JavaScript
- DOM manipulation
- Event listeners
